# GitHub CI for the C++ KMIP Libraries — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Actions CI (build-test matrix with Cosmian KMS integration tests, clang-format check, Doxygen build) triggered on master pushes and pull requests.

**Architecture:** One workflow (`.github/workflows/ci.yml`) with three jobs; Cosmian-specific machinery lives in `ci/` shell scripts so CI steps are reproducible locally. The integration tests are env-var driven (`KMIP_ADDR` etc.) and skip when unconfigured, so CI fails on any skipped test.

**Tech Stack:** GitHub Actions (ubuntu-24.04), CMake + Ninja, GCC/Clang, Cosmian KMS 5.21.0 (static non-FIPS .deb), clang-format 18.1.8 (PyPI wheel, pinned), Doxygen + graphviz.

**User decisions (already made):**
- Build + ALL tests in CI, against Cosmian KMS — explicitly not PyKMIP ("we moved all of our recent testing to cosmian-kms", per pg_tde's `ci_scripts/ubuntu-deps.sh` and `t/CosmianKms.pm`).
- Matrix: GCC + Clang, each Release and Debug+ASAN (4 cells).
- Extra jobs: clang-format check and Doxygen docs build.
- Format scope: `kmipcore/` + `kmipclient/` only (legacy `libkmip/`, `kmippp/` exempt).
- Work lands directly on `master`; behavior is validated on the user's fork (`dutow` remote). CI triggers: push to master + all pull requests.
- Approach: thin workflow + helper scripts in `ci/` (Approach 1 from brainstorming).

**Design spec:** `docs/superpowers/specs/2026-06-12-github-ci-design.md`

**Facts discovered during planning (do not re-derive):**
- Integration tests read `KMIP_ADDR`, `KMIP_PORT`, `KMIP_CLIENT_CA` (client cert PEM), `KMIP_CLIENT_KEY`, `KMIP_SERVER_CA` (CA PEM), `KMIP_TIMEOUT_MS`, and the flag `KMIP_RUN_2_0_TESTS` (`kmipclient/tests/KmipClientIntegrationTest.cpp:68-110`). They `GTEST_SKIP()` when unset.
- Cosmian install recipe (from pg_tde `ci_scripts/ubuntu-deps.sh`): pinned 5.21.0 .deb from `package.cosmian.com`, then `chmod 0755` on `/usr/sbin/cosmian_kms` and `/usr/local/cosmian/lib/ossl-modules/legacy.so` (shipped 0500 root:root).
- Cosmian run recipe (from pg_tde `t/CosmianKms.pm`): TOML config (CLI flags are silently ignored when a TOML exists), self-signed test CA + server cert `CN=127.0.0.1` with `subjectAltName=IP:127.0.0.1` exported to PKCS#12 (password `test`), client cert in PEM; readiness = `curl -fsSk -m 1 https://127.0.0.1:<http_port>/version` polled for 15 s; needs `OPENSSL_MODULES` set.
- The tree is NOT clang-format clean: 760 violations across ~30 files in `kmipcore`/`kmipclient` under clang-format 18.1.8 → preparatory reformat commit required (anticipated in the spec).
- CI pins clang-format via `pipx install clang-format==18.1.8` instead of the distro package (spec refinement: the PyPI wheel gives the identical binary locally and in CI; ubuntu-24.04's distro package is 18.1.3, which may format differently).
- Local dev machine is openSUSE: no `dpkg`. `ci/install-cosmian.sh` is CI-only; `ci/start-cosmian.sh` honors `COSMIAN_KMS_BIN` so it runs locally against a deb extracted with `ar x` + `tar`.
- Git remotes: `dutow` = `git@github.com:dutow/libkmip.git` (the fork, push target), `origin` = upstream `Percona-Lab/libkmip` (do NOT push there).
- gcc/clang are preinstalled on ubuntu-24.04 runners; `apt-get install clang` is a fast no-op kept for robustness.
- **Discovered during Task 1 execution:** the KMIP 2.0 suite (`KmipClientIntegrationTest20.*`, 28 tests) is only registered in CTest when `KMIP_RUN_2_0_TESTS=1` is exported at BUILD time — `gtest_discover_tests` lists tests post-build and `main()` filters the 2.0 suite out of the listing when the flag is unset. The flag must therefore be set during build AND test (job-level env in CI).
- **Discovered during Task 1 execution:** two 1.4-suite skips are intentional and environment-independent: `KmipClientIntegrationTest.NetClientOpenSSLCanRetryAfterFailedConnect` (only runs when the first TLS connect fails; with a correct cert/SAN setup it always skips) and `KmipClientIntegrationTest.LocatePageByGroupReportsLocatedItemsWhenServerProvidesIt` (Cosmian's 1.4 Locate response legally omits optional `LocatedItems`; the 2.0 variant passes). The skip guard allowlists exactly these two instead of demanding zero skips.

- [ ] **Step 1: Write `ci/install-cosmian.sh`** (CI-only; Ubuntu runner)

```bash
#!/usr/bin/env bash
# Installs the pinned Cosmian KMS server on an Ubuntu CI runner.
# Usage: ci/install-cosmian.sh [cache-dir]
set -euo pipefail

COSMIAN_VERSION=5.21.0
CACHE_DIR="${1:-$HOME/cosmian-deb}"
ARCH=$(dpkg --print-architecture)
DEB="cosmian-kms-server-non-fips-static-openssl_${COSMIAN_VERSION}_${ARCH}.deb"

mkdir -p "$CACHE_DIR"
if [ ! -f "$CACHE_DIR/$DEB" ]; then
  wget -q -O "$CACHE_DIR/$DEB.tmp" \
    "https://package.cosmian.com/kms/${COSMIAN_VERSION}/deb/${ARCH}/non-fips/static/${DEB}"
  mv "$CACHE_DIR/$DEB.tmp" "$CACHE_DIR/$DEB"
fi

sudo dpkg -i "$CACHE_DIR/$DEB"
# .deb ships binary + bundled legacy.so as 0500 root:root; CI runner is non-root.
sudo chmod 0755 /usr/sbin/cosmian_kms
sudo chmod 0755 /usr/local/cosmian/lib/ossl-modules/legacy.so
```

- [ ] **Step 2: Write `ci/start-cosmian.sh`** (portable: CI and local dev)

```bash
#!/usr/bin/env bash
# Starts a throwaway Cosmian KMS for the kmipclient integration tests.
# Usage: ci/start-cosmian.sh <workdir>
# Uses cosmian_kms from PATH, or $COSMIAN_KMS_BIN when set.
# Appends KMIP_* test variables to $GITHUB_ENV when set (CI);
# otherwise prints "export KMIP_*=..." lines for eval (local use).
# The server keeps running; stop it with: kill "$(cat <workdir>/cosmian.pid)"
set -euo pipefail

WORKDIR="${1:?usage: start-cosmian.sh <workdir>}"
BIN="${COSMIAN_KMS_BIN:-$(command -v cosmian_kms || true)}"
if [ -z "$BIN" ]; then
  echo "cosmian_kms not found on PATH; install it or set COSMIAN_KMS_BIN" >&2
  exit 1
fi
mkdir -p "$WORKDIR"
WORKDIR="$(cd "$WORKDIR" && pwd)"
cd "$WORKDIR"

openssl req -x509 -newkey rsa:2048 -nodes -days 1 \
  -keyout ca.key -out ca.pem -subj '/CN=libkmip-test-ca'
openssl req -newkey rsa:2048 -nodes -keyout server.key -out server.csr \
  -subj '/CN=127.0.0.1' -addext 'subjectAltName=IP:127.0.0.1'
openssl x509 -req -in server.csr -CA ca.pem -CAkey ca.key -CAcreateserial \
  -days 1 -out server.pem -copy_extensions copy
openssl pkcs12 -export -out server.p12 -inkey server.key -in server.pem \
  -password pass:test
openssl req -newkey rsa:2048 -nodes -keyout client.key -out client.csr \
  -subj '/CN=libkmip-test-client'
openssl x509 -req -in client.csr -CA ca.pem -CAkey ca.key -CAcreateserial \
  -days 1 -out client.pem

free_port() {
  python3 -c 'import socket; s = socket.socket(); s.bind(("127.0.0.1", 0)); print(s.getsockname()[1]); s.close()'
}
KMIP_PORT="$(free_port)"
HTTP_PORT="$(free_port)"

cat > kms.toml <<TOML
default_username = "admin"

[db]
database_type = "sqlite"
sqlite_path   = "$WORKDIR/db"
clear_database = true

[tls]
tls_p12_file         = "$WORKDIR/server.p12"
tls_p12_password     = "test"
clients_ca_cert_file = "$WORKDIR/ca.pem"

[socket_server]
socket_server_start    = true
socket_server_port     = $KMIP_PORT
socket_server_hostname = "127.0.0.1"

[http]
port     = $HTTP_PORT
hostname = "127.0.0.1"

[logging]
rust_log = "info,cosmian_kms=info"
TOML

# Cosmian needs OPENSSL_MODULES; autodetect common locations when unset.
if [ -z "${OPENSSL_MODULES:-}" ]; then
  for d in /usr/local/cosmian/lib/ossl-modules /usr/lib64/ossl-modules \
           /usr/lib/x86_64-linux-gnu/ossl-modules \
           /usr/lib/aarch64-linux-gnu/ossl-modules; do
    if [ -d "$d" ]; then
      export OPENSSL_MODULES="$d"
      break
    fi
  done
fi

"$BIN" -c "$WORKDIR/kms.toml" > "$WORKDIR/cosmian.log" 2>&1 &
echo $! > "$WORKDIR/cosmian.pid"

ready=""
for _ in $(seq 1 75); do  # 15 s total, 200 ms steps
  if curl -fsSk -m 1 "https://127.0.0.1:$HTTP_PORT/version" > /dev/null 2>&1; then
    ready=1
    break
  fi
  sleep 0.2
done
if [ -z "$ready" ]; then
  echo "cosmian_kms did not become ready within 15s" >&2
  cat "$WORKDIR/cosmian.log" >&2
  kill "$(cat "$WORKDIR/cosmian.pid")" 2> /dev/null || true
  exit 1
fi

VARS="KMIP_ADDR=127.0.0.1
KMIP_PORT=$KMIP_PORT
KMIP_CLIENT_CA=$WORKDIR/client.pem
KMIP_CLIENT_KEY=$WORKDIR/client.key
KMIP_SERVER_CA=$WORKDIR/ca.pem
KMIP_TIMEOUT_MS=5000
KMIP_RUN_2_0_TESTS=1"

if [ -n "${GITHUB_ENV:-}" ]; then
  echo "$VARS" >> "$GITHUB_ENV"
else
  echo "$VARS" | sed 's/^/export /'
fi
```

Then `chmod +x ci/install-cosmian.sh ci/start-cosmian.sh`.

# Checks formatting of the new C++ libraries (kmipcore, kmipclient).
# Legacy code (libkmip, kmippp) is intentionally exempt.
# Requires clang-format 18.1.8 on PATH (CI installs it via pipx; locally:
# pip install clang-format==18.1.8).

cd "$(dirname "$0")/.."

ver="$(clang-format --version)"

if [[ "$ver" != *"version 18.1.8"* ]]; then

  | xargs -0r clang-format --dry-run --Werror; then
  echo "formatting OK"
else

  exit 1

**Steps:**

- [ ] **Step 1: Write `.github/workflows/ci.yml`**

```yaml
name: CI

on:
  push:
    branches: [master]
  pull_request:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read

jobs:
  build-test:
    name: ${{ matrix.compiler }} ${{ matrix.build }}
    runs-on: ubuntu-24.04
    timeout-minutes: 30
    strategy:
      fail-fast: false
      matrix:
        compiler: [gcc, clang]
        build: [Release, ASAN]
    env:
      CC: ${{ matrix.compiler == 'gcc' && 'gcc' || 'clang' }}
      CXX: ${{ matrix.compiler == 'gcc' && 'g++' || 'clang++' }}
      # Must be set at BUILD time too: gtest test discovery runs post-build
      # and filters the KMIP 2.0 suite out of the listing when unset.
      KMIP_RUN_2_0_TESTS: 1
    steps:
      - uses: actions/checkout@v4

      - name: Install dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libssl-dev ninja-build clang

      - name: Cache Cosmian KMS package
        uses: actions/cache@v4
        with:
          path: ~/cosmian-deb
          key: cosmian-kms-5.21.0-${{ runner.arch }}

      - name: Install Cosmian KMS
        run: ci/install-cosmian.sh ~/cosmian-deb

      - name: Configure
        run: >
          cmake -S . -B build -G Ninja
          -DCMAKE_BUILD_TYPE=${{ matrix.build == 'ASAN' && 'Debug' || 'Release' }}
          -DWITH_ASAN=${{ matrix.build == 'ASAN' && 'ON' || 'OFF' }}
          -DBUILD_TESTS=ON
          -DBUILD_KMIP_TESTS=ON

      - name: Build
        run: cmake --build build -j

      - name: Start Cosmian KMS
        run: ci/start-cosmian.sh "${{ runner.temp }}/cosmian"

      - name: Test
        run: |
          ctest --test-dir build --output-on-failure
          log=build/Testing/Temporary/LastTest.log
          if grep -F 'environment variables not configured' "$log"; then
            echo "::error::KMIP test environment not configured; integration tests skipped"
            exit 1
          fi
          if ! grep -q 'KmipClientIntegrationTest20\.' "$log"; then
            echo "::error::KMIP 2.0 test suite did not run"
            exit 1
          fi
          # 'listed below' filters gtest's count-summary line, which names no test
          unexpected=$(grep -F '[  SKIPPED ]' "$log" \
            | grep -v -e 'listed below' \
                      -e 'NetClientOpenSSLCanRetryAfterFailedConnect' \
                      -e 'KmipClientIntegrationTest\.LocatePageByGroupReportsLocatedItemsWhenServerProvidesIt' \
            || true)
          if [ -n "$unexpected" ]; then
            echo "::error::unexpected skipped tests:"
            echo "$unexpected"
            exit 1
          fi

      - name: Upload failure artifacts
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: failure-${{ matrix.compiler }}-${{ matrix.build }}
          path: |
            ${{ runner.temp }}/cosmian/cosmian.log
            ${{ runner.temp }}/cosmian/kms.toml
            build/Testing/
          if-no-files-found: ignore

  format:
    runs-on: ubuntu-24.04
    steps:
      - uses: actions/checkout@v4

      - name: Install clang-format
        run: pipx install clang-format==18.1.8

      - name: Check formatting
        run: ci/check-format.sh

  docs:
    runs-on: ubuntu-24.04
    steps:
      - uses: actions/checkout@v4

      - name: Install Doxygen
        run: |
          sudo apt-get update
          sudo apt-get install -y doxygen graphviz

      - name: Build docs
        run: |
          cmake -S . -B build-docs -DBUILD_DOCS=ON
          cmake --build build-docs --target doc
```
